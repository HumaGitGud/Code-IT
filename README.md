# Code-It
A setup for The Littlest JupyterHub on a DigitalOcean VM to facilitate RTC peer-programming.

## Team Members
- Ash Gray
- Huma Khomidov
- Maxwell Maslov
- Rudolf Sirbu

## Project Description
This project enables real-time collaborative programming in JupyterHub, allowing students to work together on code in the same notebook.

## Development Setup for TLJH
- Follow [TLJH-Setup.md](https://github.com/HumaGitGud/Code-IT/blob/main/TLJH-Setup.md) for TLJH + RTC setup on DigitalOcean VM
- Follow [tljh-html-editor-config.md](https://github.com/HumaGitGud/Code-IT/blob/main/tljh-html-editor-config.md) for HTML viewing setup on DigitalOcean VM
- Follow [Kubernetes-Report.md](https://github.com/HumaGitGud/Code-IT/blob/main/Kubernetes-Report.md) for documentation on local Kubernetes Setup
